# ⚙️ Laravel

## 📦 Установка зависимостей

Убедитесь, что у вас установлен [Composer](https://getcomposer.org/).  
Установить зависимости:

```bash
composer install
```

# 🛠️ Конфигурация окружения
Переименуйте .env.example в .env в корне проекта и настройте параметры окружения.
Сгенерируйте ключ приложения:

```bash
php artisan key:generate
```

# 🧪 Скрипты проекта

| Команда                      | Назначение                                                                 |
|-----------------------------|----------------------------------------------------------------------------|
| `php artisan serve`         | Запускает локальный сервер Laravel.                                       |
| `php artisan migrate`       | Выполняет миграции базы данных.                                           |
| `php artisan db:seed`       | Запускает сидеры (наполнение базы тестовыми данными).                     |
| `php artisan migrate:fresh` | Очищает и повторно применяет миграции.                                    |
| `php artisan test`          | Запускает тесты.                                                           |
| `php artisan route:list`    | Показывает список доступных маршрутов.                                     |
| `php artisan config:cache`  | Кэширует конфигурации приложения.                                          |
| `php artisan cache:clear`   | Очищает кэш приложения.                                                    |
| `php artisan optimize`      | Оптимизирует производительность приложения (кэш, автозагрузка и т.д.).    |
